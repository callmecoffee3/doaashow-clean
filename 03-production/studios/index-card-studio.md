# Index Card Studio

Make micro dramas from **index cards**.

## Rules (lab style)

- Up to **100 cards** per project
- Max **~500 characters** per card
- Card types: Character, Scene, Prop, Animal, Prompt, Title
- User (or project) can set the **title**
- Cards → ordered deck → generate vertical micro-drama

## Project title

User can add a title to the project, or the studio will use a default like:

> Untitled MicroDrama • [date]

## Workflow

1. New Project → give it a title
2. Add cards (max 100)
3. Arrange order
4. Generate / export HTML or short video mock

See also: `reelwave-studio` for the full social + generation UI.
