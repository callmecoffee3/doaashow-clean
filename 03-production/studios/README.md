## How studios work here

1. Each studio gets its own folder under `03-production/` or a subfolder here.
2. Prefer single-file HTML or small web apps so they open in a browser.
3. User-generated content, posts, groups, and pages live with the studio (see ReelWave).
4. New studios: create a folder + README + main HTML/app file.
