# ReelWave Micro Drama Studio

**Big Drama. Small Screen. Make your own.**

User-generated micro-drama creation studio + social platform for the DoAShow lab.

## Features

- **Studio** — AI-style micro-drama generator with index cards (Character / Scene / Prop / Animal / Prompt)
- **Community Feed** — posts, stories, likes, vertical drama cards
- **Groups** — CEO Romance Writers, MicroDrama Lab, The Fam Creators, Vertical Only
- **Pages** — creator pages (Elena, ReelWave Official, Matt Grosso)
- **Shop** — coins, script packs, actor packs, scenes, music
- **Messenger** — chats with creators & The Fam

## How to open

Open `reelwave-studio.html` in any modern browser (phone-first layout).
