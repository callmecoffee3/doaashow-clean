# MicroDrama Lab

**Big Drama. Small Screen.**  
Community feed + Creators Corner + Writers Corner + AI Studio

Single-file web app for the doaashow creative lab.

## Features

### Community Feed
- Posts: clips, theories, collab asks
- Filter tabs: All / Clips / Theories / Collabs
- Like, comment, share (demo)
- Composer tease for signed-in posts

### Creators Corner
- Series dashboard (My Series)
- Stats: series count, views, collab requests, coins
- Open Collabs board (writer / editor / actor roles)
- Creator tools: thumbnail gen, scheduler, analytics, link to AI Studio

### Writers Corner
- Script Boards (outline / full script / idea dumps)
- Logline Lab — sample loglines with “Use in Studio”
- Trope Library — heat ratings for popular micro-drama tropes
- Feedback Loop placeholder

### AI Studio
- Free-form prompt → simulated multi-step generation
- Vertical (9:16) video player
- Optional “include project cards” toggle (stub)
- Demo video source for now

## How to run

Open `microdrama-app.html` in any modern browser.  
No build step. Tailwind + Font Awesome via CDN. All state is client-side demo data.
