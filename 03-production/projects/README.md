## How projects work

1. Each project can have a **title** (user sets it or default is used)
2. Index cards: up to **100 cards**, ~**500 characters** each
3. Card types: Title, Character, Scene, Prop, Animal, Prompt, Dialogue, Hook
4. Link to a Studio (ReelWave / Index Card Studio) to generate
5. Optional: post to community, groups, pages
